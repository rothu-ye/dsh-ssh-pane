# SSH 右侧终端

把 dsh-ssh 的主机终端开到**右侧栏**里，中央区域继续留给会话。

dsh-ssh 自己只注册了两个座位：左侧导航的一行，和中央区域的一整页。点它会把会话顶掉。这个插件补上第三个座位——右侧栏的一个标签页，于是「左边看对话、右边敲命令」可以同时成立。

## 用法

1. 右侧栏展开（会话标题栏右上角的展开按钮，或快捷键）。
2. 在起始页或标签栏的 `+` 里选择 **SSH 终端**。
3. 顶部下拉框选一台已在 dsh-ssh 里配置好的主机，终端自动连接。
4. 断线或换主机后点 **重连**。

主机列表、连接池、凭据全部来自 dsh-ssh，本插件不保存任何配置，也不新增任何路由（除了它自己的三个静态资源）。

## 与 dsh-ssh 面板的区别

| | dsh-ssh 面板 | 本插件 |
|---|---|---|
| 位置 | 中央区域整页 | 右侧栏标签页 |
| 会话 | 被顶掉 | 保留在中央 |
| 主机管理 / 密钥 / 传输 / 隧道 | 有 | 没有，去左侧 SSH 面板 |
| 终端 | 多标签 | 单标签，内置主机切换与重连 |

## 已知限制

- 只支持 dsh-ssh 已经支持的连接方式，因为它复用的就是 dsh-ssh 的终端协议（`/api/dsh-ssh/terminal` 的 WebSocket）。
- 一个标签页一个 PTY。需要同时对多台机器开会话时，切换主机即可（会结束上一个会话），或改用 dsh-ssh 面板的多标签终端。
- `keepMounted` 打开：切到别的标签不会断开进程内会话；关闭标签会发送 `close` 帧并结束远端 shell。
- 页面由 Electron 以 `dsh-app://` 交付时，WebSocket 地址改由 `__DSH_TRANSPORT__.streamBaseUrl` 推导；普通 http 页面直接用自身 origin。
- 顶部状态只反映终端通道状态，不代表远端命令的成功与否。

## 实现说明

- 宿主半只做一件事：以精确路径路由提供 `assets/` 下的 xterm UMD 构建、fit 插件和样式表。它们从 `@xterm/xterm` 与 `@xterm/addon-fit`（MIT）复制而来，因此本插件安装成副本或链接目录都能工作，不依赖模块解析。
- 浏览器半通过 `sidebarRightTabs.register({ id, kind, ... })` 声明标签类型，再用 `slots.register({ name: 'sidebar.right.pane.tab', key })` 画内容——和 DSH 自带的文件、浏览器、终端页走同一套公开座位。
- 终端配色取自页面主题变量（`--dsw-alias-*`），随明暗主题切换。
